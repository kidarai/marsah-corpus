# Marsah Corpus

[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](https://opensource.org/licenses/MIT)

Gates and stacks corpus for [`Marsah`](https://github.com/kidarai/marsah), a deterministic controller for AI coding agents.

This repository holds the quality-gate and technology-stack definitions Marsah reads when it builds: what counts as a passing build for a given language and stack, and what each gate actually runs. It is a companion to the engine and is not useful on its own.
